# Decision Tree Projects

Decision Trees are supervised learning models that split data into branches using feature-based decision rules.

## Classification vs. Regression Trees

- **Classification Trees** predict categorical labels (for example, survived vs. not survived).
- **Regression Trees** predict continuous values (for example, a price or score).

## Core Concepts

- **Gini Impurity:** measures how mixed classes are within a node.
- **Entropy:** measures uncertainty in class distribution.
- **Information Gain:** quantifies how much a split reduces uncertainty.

## Overfitting and Tree Depth

Deep trees can memorize training data and overfit. Controlling depth and related hyperparameters helps improve generalization to unseen data.
