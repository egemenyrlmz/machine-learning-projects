# Titanic Survival Prediction (Decision Tree)

## Project Overview

This project is the first hands-on implementation in the repository and focuses on binary classification using a Decision Tree model.

> **Status:** Planned — not implemented yet.

## Problem Statement

Given passenger information from the Titanic dataset, predict whether a passenger survived.

- **Target variable:** `Survived`
- **Dataset source:** https://www.kaggle.com/competitions/titanic/data

## Expected Input Features

The project will primarily work with features such as:

- `Pclass`
- `Sex`
- `Age`
- `Fare`
- `SibSp`
- `Parch`
- `Embarked`

## Learning Objectives

- Practice data understanding and feature preparation for classification
- Implement and evaluate a Decision Tree from an educational perspective
- Analyze overfitting behavior and model complexity
- Improve interpretation skills through tree visualization

## Planned Workflow

1. Data exploration
2. Exploratory Data Analysis
3. Data preprocessing
4. Train/test split
5. Decision Tree training
6. Model evaluation
7. Hyperparameter tuning
8. Overfitting analysis
9. Decision Tree visualization

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Dataset Placement

Download the dataset manually from Kaggle and place files here:

- `01-decision-tree/titanic-survival/data/train.csv`
- `01-decision-tree/titanic-survival/data/test.csv`

CSV files in this project data folder are intentionally ignored by Git.
